// Program loads Zeo and PSG sleep stage data sets, locates and fills gaps in Zeo data and performs interpolation of scored PSG sleep stage data file (converts from minimal file to 
// complete file suitable for stage by stage comparison) before performing comparison between data sets to arrive at percent agreement and kappa

// Zeo drops 0-2 stages per night (1 in 1000). A sleep stage determination is expected every 30 seconds. Occasionally, a sleep stage is dropped resulting in consecutive stages being
// 1 minute apart rather than 30 seconds. Also, while it highly unlikely, it is possible for more than one stage to be dropped in succession, resulting in two consecutive stages being
// separated by more than 1 minute. For instance, if approx. 1 out of every 1000 stages gets dropped, then there is 1 in 1 million chance that two successive sleep stages in a night will be
// dropped. Program accounts for that possibility (gap consisting of more than 1 missed sleep stage). Gap is filled in with a "MISSING" descriptor rather than filling gap with last stage
// value (conservative approach). Were this drop effect not taken into account, data sets would be out of sync by 30 sec (in addition to the minimized misalignment between them), 
// and the data sets would become misaligned by an additional 30 sec every time Zeo dropped a stage.

// File generated by Grass from scored study is a minimal file showing only when stage changes: from minimal file, a  complete file may be generated (reconstructed) by interpolating or filling in the gaps

// Program finds nearest time in PSG sleep stage data to the starting point specified for the Zeo sleep stage data and performs a comparison and evaluation of true, false, or N/A

// Comparison is only made if valid stages are present in both data sets: if Zeo stage is UNK (headband off) or "MISSING" (corresponding to gap) or if PSG stage is "No Stage"(corresponding to 
// disconnection as for bathroom break), then no stage comparison is made
